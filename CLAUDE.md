# Team rules
- Never commit .env or API keys. Keys live in .env only, and each person uses their own.
- Never push straight to main. Work on a branch and open a pull request.
- Pull main before starting new work, and keep commits small with clear messages.
- Ask before adding new packages, and add them to the requirements file.
- To run the project: `npm install` then `npm start`, open http://localhost:3000. Tests: `npm test`.
