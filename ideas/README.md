# Ideas

Drop your hackathon ideas here. Anything goes: half-formed thoughts, features, names, things you saw somewhere. We'll go through them all and build something from the best bits.

## How to add an idea

1. Create a new file in this folder named `yourname-short-title.md` (for example `oliver-table-booking.md`).
2. Use the template below. Keep it short, a few lines is fine.
3. Commit it on a branch and open a pull request, or just paste it into the team chat and someone will add it.

## Template

```
# Idea title

**Who:** your name
**What:** one or two sentences on the idea
**Why:** what problem it solves or why it would be fun
**Notes:** anything else (links, sketches, tech it might need)
```
